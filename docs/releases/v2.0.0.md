**Дата випуску:** … · **Команда:** «Натурали», ТР-41

## Відомі обмеження

1. **Якість стилю залежить від моделі ШІ.** `moondream` часто відповідає «стиль не визначено» і на процесорі може не встигнути за 30 с — тоді показується результат без ШІ з повідомленням.
2. **Безкоштовний тариф Gemini** обмежує кількість запитів на добу; перевищення (`429`) чи перевантаження сервісу (`503`) → результат без ШІ.
3. **Добір потребує калібрування:** за яскравого освітлення світлі предмети стилю відсіюються правилом освітленості, і вільні місця займають предмети інших стилів; комплементарний колір (R1) може підняти яскравий предмет вище.
4. **Повторний аналіз** в іншому режимі — лише після повторного завантаження фото.
5. **Фото ~10 МБ** не зберігаються в галерею (#53).
6. **Роботи без стилю** (до S2, «без ШІ», «стиль не визначено») видно лише в «Усі стилі».
7. **Освітленість (AC-04, v1)** і **SixLabors.ImageSharp 3.1.12** (попередження NU1902/NU1903) — як у [v1.0.0](v1.0.0.md#відомі-обмеження).

## Запуск

Потрібні .NET 8 SDK і база PostgreSQL (Neon).

1. Скопіювати `.env.example` у `.env` і задати `ConnectionStrings__Default`, `ApiBaseUrl`; за бажанням — `Ai__Gemini__ApiKey` (хмарний ШІ) або запустити Ollama з моделлю для зображень (локальний ШІ).
2. `dotnet run`. У `Development` міграції застосовуються під час старту; для `Production` — вручну `dotnet ef database update`.

Докладніше — [README](../../README.md).
