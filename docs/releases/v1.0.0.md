# AiDesigner v1.0.0

**Дата випуску:** 29.10.2026 · **Команда:** «Натурали», ТР-41

Перший випуск «ШІ-дизайнера інтер'єру»: користувач завантажує фото кімнати, отримує колірну гаму й оцінку освітленості, вибирає один із запропонованих предметів, розміщує його на фото й зберігає результат як PNG.

## Що входить

| UC | Що вміє | Автор |
|----|---------|-------|
| UC-01 | Завантаження фото JPEG/PNG: перевірка розміру (≤ 10 МБ), формату й розмірів за вмістом файла | Блонський Іван |
| UC-02 | Аналіз фото: 3–5 домінантних кольорів із частками (сума 100 %), освітленість «темне / помірне / яскраве» | Фріз Богдан |
| UC-03 | Добір 3–4 предметів із каталогу за правилами R1–R5 з поясненням | Онищук Дмитро |
| UC-04 | Розміщення предмета на фото (перетягування, масштаб), збереження PNG | Семенюта Іван |

- Каталог — 24 предмети (`wwwroot/data/catalog.json`), зображення pngimg.com за CC BY-NC 4.0.
- Фото користувача не зберігається й не передається за межі сервера (NFR-04).
- 379 автотестів (xUnit).

## Зміни вимог після baseline

- **CR-01** — R1: нейтральні домінантні кольори не враховуються в колірній гармонії.
- **CR-02** — пороги освітленості 85/170 → 55/125 (калібрування на реальних фото).
- **CR-03** — R3: спершу предмети різних типів, не більше двох одного типу.

Деталі — [requirements.md](../requirements.md#зміни-після-baseline).

## Приймання

17 з 18 критеріїв пройдено, AC-04 не пройдено. Звіт — [acceptance.md](../acceptance.md).

## Відомі обмеження

1. **Освітленість (AC-04: 4 з 6 на незалежному наборі).** Автоекспозиція камери вирівнює яскравість кадру, тож похмурі «помірні» сцени можуть потрапити в «темне».
2. **Домінантний колір рахується за площею** — підлога й меблі можуть переважити стіни; кольорове освітлення змінює гаму.
3. **Пропозиції повторюються для «теплих» кімнат** — каталог невеликий і здебільшого теплих відтінків.
4. **Дрібні яскраві акценти** можуть не потрапити в палітру.
5. **SixLabors.ImageSharp 3.1.12** має відомі вразливості (попередження NU1902/NU1903); виправлення є лише в ліцензованій 4.x. Межа 50 Мп на розкодування зменшує ризик «декомпресійної бомби».

