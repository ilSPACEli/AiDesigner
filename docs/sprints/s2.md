# Спринт S2 (ЛР №6)

## План

**Мета S2:** система визначає стиль кімнати (режими «Аналіз без ШІ», «Локальний ШІ», «Хмарний ШІ») і враховує його в доборі; каталог містить предмети кожного стилю; аналіз зберігається разом із роботою в галереї.

**Відібрані історії:**
- US-2 «Аналіз стилю кімнати» (#20). Оцінка: 8.
- US-3 «Стилі в каталозі» (#34). Оцінка: 4.

**Предметні правила:** R8 «прийняття стилю» (поріг упевненості 0,6), R6 «відповідність стилю» (+1 бал). Контрольні приклади — у картці #20.

**Залежності:**
- Контракт (`docs/api.md`, перелік стилів) — у S2-0, до паралельної роботи.
- **Схема (S2-3) мержиться першою**: поле `Style` потрібне S2-4 і S2-5. Міграції в S2 створює лише Фріз.
- S2-4 (правило R6) пишеться одразу як окремий клас; підключення до добору — після S2-3.
- S2-6 до готовності S2-1 працює з фейковими режимами.
- S2-2 — після S2-1 (спільний інтерфейс і промпт).

**Умови готовності (Definition of Done):**
- критерії приймання історій виконано (AC-12, AC-26…AC-35);
- злито в `dev` через PR із посиланням на задачу;
- CI зелений до запиту на рев'ю; незалежне рецензування (Approve);
- у PR правила — контрольні приклади й результати модульних тестів; хоча б один коміт зібрано через `git add -p`;
- міграцію перевірено на копії БД — наявні записи збереглися;
- оновлено діаграму послідовності свого сценарію (ЛР №4) за фактичним кодом;
- сценарії v1 і S1 працюють; README / `.env.example` актуальні.
