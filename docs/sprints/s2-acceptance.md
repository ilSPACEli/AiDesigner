### 2.7. AC-33 — контрольована відмова на копії БД

Гілка Neon від `production` → `.env` на гілку → `dotnet ef database update` → тригер → «Зберегти в галерею» → прибрати тригер → «Зберегти» ще раз.

```sql
CREATE FUNCTION fail_analysis_insert() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
    RAISE EXCEPTION 'Контрольована відмова: запис аналізу заборонено';
END $$;
CREATE TRIGGER fail_analysis_insert BEFORE INSERT ON "ResultAnalyses"
FOR EACH ROW EXECUTE FUNCTION fail_analysis_insert();

SELECT COUNT(*) AS works FROM "SavedResults";
SELECT COUNT(*) AS analyses FROM "ResultAnalyses";

DROP TRIGGER fail_analysis_insert ON "ResultAnalyses";
DROP FUNCTION fail_analysis_insert();
```

| Крок | `SavedResults` | `ResultAnalyses` | Повідомлення |
|---|---|---|---|
| до | 1 | 1 | — |
| з тригером | 1 (без змін) | 1 (без змін) | інтерфейс: «Не вдалося зберегти зображення. Спробуйте ще раз.»; лог сервера: `P0001: Контрольована відмова: запис аналізу заборонено` |
| без тригера | 2 (+1) | 2 (+1) | — |

## 3. Відомі обмеження

- Якість визначення стилю залежить від моделі ШІ. `moondream` часто відповідає «стиль не визначено» і на процесорі може відповідати довше за 30 с (тоді — результат без ШІ, AC-30). Великі моделі (`gemma3:12b`) без достатньої пам'яті повертають помилку.
- Хмарний ШІ на безкоштовному тарифі Gemini: обмеження запитів (для `gemini-3.8-flash` — 20 на добу); перевищення (`429`) або перевантаження сервісу (`503`) → результат без ШІ (AC-30). Для розробки й демонстрації — `gemini-flash-lite-latest`.
- Повторний аналіз в іншому режимі можливий лише після повторного завантаження фото — перенесено в беклог.
- Добір: R6 діє лише на предмети, що пройшли за кольором і освітленістю. За яскравого освітлення більшість світлих предметів «Мінімалізм» відсіюються R2, і вільні місця займають предмети інших стилів; комплементарний колір (R1, 2 бали) може підняти яскравий предмет вище. Калібрування правил і даних каталогу — S3.
- R1 слабко розрізняє темні нейтральні фото.
- Великі фото (~10 МБ) не зберігаються в галерею — #53.

## 4. Висновок

Усі критерії S2 (AC-12, AC-26…AC-35) пройдено; сценарії v1 і S1 працюють. Обмеження з розд. 3 не порушують критеріїв приймання й винесені в беклог (#53, калібрування добору, повторний аналіз).
