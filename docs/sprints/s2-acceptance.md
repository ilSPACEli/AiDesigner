### 2.7. AC-33 — контрольована відмова на копії БД

Гілка Neon від `production` → `.env` на гілку → `dotnet ef database update` → тригер → «Зберегти в галерею» → прибрати тригер → «Зберегти» ще раз.

```sql
CREATE FUNCTION fail_analysis_insert() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
    RAISE EXCEPTION 'Контрольована відмова: запис аналізу заборонено';
END $$;
CREATE TRIGGER fail_analysis_insert BEFORE INSERT ON "ResultAnalyses"
FOR EACH ROW EXECUTE FUNCTION fail_analysis_insert();

SELECT COUNT(*) AS works FROM "SavedResults";
SELECT COUNT(*) AS analyses FROM "ResultAnalyses";

DROP TRIGGER fail_analysis_insert ON "ResultAnalyses";
DROP FUNCTION fail_analysis_insert();
```

## 3. Відомі обмеження

- Якість визначення стилю залежить від моделі ШІ; Moondream на процесорі може відповідати довше за 30 с (тоді — результат без ШІ, AC-30).
- Великі фото (~10 МБ) не зберігаються в галерею — #53.
